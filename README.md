# PRODIGY_ML_04

## Hand Gesture Recognition using CNN and SVM

This project is part of the Machine Learning Internship at Prodigy Infotech.

---

## 📌 Task Objective

Develop a hand gesture recognition model capable of accurately identifying and classifying different hand gestures from image data, enabling intuitive human-computer interaction and gesture-based control systems.

---

## 📂 Dataset

Dataset used:  
https://www.kaggle.com/gti-upm/leapgestrecog

Download and extract the dataset, then place it in the project directory before running the script.

---

## 🛠️ Technologies & Libraries Used

- Python
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras
- OpenCV / Pillow

---

## 📊 Project Features

- Hand gesture image preprocessing
- CNN-based gesture recognition
- SVM baseline classifier
- PCA dimensionality reduction
- Model evaluation and accuracy analysis
- Confusion matrix visualization
- Training history visualization
- Multi-class gesture classification
- Saved trained CNN model (`.keras`)

## ▶️ How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/PRODIGY_ML_04.git
```

### 2. Install Required Libraries

```bash
pip install numpy matplotlib scikit-learn tensorflow opencv-python pillow
```

### 3. Download Dataset

Download dataset from Kaggle and extract it into:

```text
leapgestrecog/
```

### 4. Run the Script

```bash
python task4.py
```
